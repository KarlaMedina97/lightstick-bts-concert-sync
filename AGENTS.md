# AGENTS.md

Instrucciones para agentes de código (Codex, Copilot, Cursor, Claude Code y otros).

La guía completa está en **[CLAUDE.md](CLAUDE.md)**: comandos, mapa del código y reglas obligatorias.

Lo esencial:

1. `npm run check` debe pasar antes de terminar.
2. Sin letras de canciones, logo de BTS, CDNs ni scripts en línea.
3. Conventional Commits en español, sin trailers `Co-Authored-By` de IA.
4. Accesible, responsivo y con modo seguro (máx. 3 destellos/s).
